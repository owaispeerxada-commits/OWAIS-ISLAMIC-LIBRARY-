# DEEN DAILY — starter PWA

This is a small working starter website/PWA designed for a green-and-gold Islamic app.
 
## Test it
1. Extract this ZIP.
2. Open `index.html` in a browser to preview the layout (some PWA features need hosting).
3. For install/offline support, host the folder on an HTTPS static host such as GitHub Pages.
4. Open the hosted URL in Chrome on Android → menu ⋮ → **Install app** or **Add to Home screen**.

## Important
- This is a starter prototype, not a finished religious reference app.
- Verify Quran text, translations, Hadith wording and references with trusted sources/scholars before public release.
- The Quran section currently includes Al-Fatihah and Al-Ikhlas only.
- The Hadith section contains one short narration with a reference note; verify edition/numbering.
- Stories and a full wallpaper library are placeholders.
- This PWA can be installed on Android, but it is not yet a Play Store APK/AAB. Publishing to Play Store requires a separate Android packaging and testing step.
